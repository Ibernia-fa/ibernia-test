# Volume sign-off template

Unified sign-off for a **Phase A write + Phase B read** pair. Generated by:

```powershell
node tools/generate-volume-signoff.mjs `
  --pair-run-tag S1-write-20260602-1505 `
  --phase-a-run-tag S1-write-20260602-1505 `
  --phase-b-run-tag S1-write-20260602-1505-read `
  --expected-shards 20
```

Output: `reports/phase-volume/{pairRunTag}_SIGNOFF.md` and `{pairRunTag}_signoff-fleet.json`.
